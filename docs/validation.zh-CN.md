# 验证报告

状态：0.1.0a1（2026年10月）。[English](validation.md)

本报告把四类证据分开陈述、不混用：（1）新的冻结外部检验；（2）较早的留出检验，其最终点后来被复用；（3）纯开发交叉验证；（4）合成数据软件自检。训练拟合误差从不作为验证成绩。

## 1. 新的冻结外部检验——AREP #11，Copeland ZP21K5E-PFV

**协议。** 数据集、划分规则、比较方法、指标与判定标准在**下载报告之前**写定并记录哈希（`data_sources/round5_external_protocol.json`、`data_sources/round5_protocol_freeze.json`）。评分脚本运行前核对哈希，且拒绝第二次运行。

**数据。** ORNL/AHRI Low-GWP AREP 第11号报告（Shrestha、Mahderekal、Sharma、Abdelaziz，2013），附录A实测结果，<https://info.ornl.gov/sites/publications/files/Pub44928.pdf>。排量 1.24 in³/rev；名义等效转速 3499.9 rpm 由报告的额定位移率（150.69 ft³/h）换算，不是逐点实测值。两个数据集分别评分、不合并：

- 表A3，R410A，吸气温度 65°F：66 个工况 → 训练 42 / 残差校准 12 / 测试 12；
- 表A6，R32，吸气温度 65°F：55 个工况 → 35 / 10 / 10。

121 个单元由 PDF 文本层转录并与渲染页对照，全部通过冷量、功率与 EER 的打印舍入一致性检查；空白单元不填补。压力输入凸包顶点固定在训练集中，因此检验的是**域内插值**。

**结果（测试点，MARE / P95，%）。**

| 数据集 | 方法 | 流量 | 电功率 |
|---|---|---|---|
| R410A | 四参数 | 1.395 / 2.472 | 2.798 / 6.171 |
| | 四参数 + RBF | 0.360 / 0.663 | 0.263 / 0.533 |
| | 仿射 | 1.313 / 2.516 | 0.624 / 1.342 |
| | AHRI 风格十系数 | **0.294 / 0.610** | **0.136 / 0.292** |
| R32 | 四参数 | 1.242 / 2.346 | 2.223 / 4.501 |
| | 四参数 + RBF | 0.244 / 0.482 | **0.465 / 1.027** |
| | 仿射 | 0.528 / 1.490 | 1.128 / 1.771 |
| | AHRI 风格十系数 | **0.225 / 0.486** | 0.482 / 1.050 |

全部点均给出预测，无拒绝。

**预先判定。**

| 判定 | R410A | R32 |
|---|---|---|
| A：各响应 MARE≤5% 且 P95≤10% | 两种模型均达到 | 两种模型均达到 |
| B：RBF 在两个响应上均优于基础模型 | 是 | 是 |
| C：RBF 对最强基线（两响应 MARE 较大值） | 劣于（0.360 对 0.294） | 不劣于（0.465 对 0.482） |

**90% split-conformal 区间（只报告、不判定）。** 基础模型：流量覆盖 12/12、9/10，平均相对宽度 7.0%、5.6%；功率覆盖 12/12、10/10，宽度 15.8%、11.0%。RBF 扩展区间窄得多（1.0%–2.1%），但 R410A 流量只覆盖 9/12。10–12 个点不足以可靠估计覆盖率。

**选点策略（次要分析）。** random、maximin、局部 D 最优和核方差（kernel IVR）四种顺序在评分前冻结（5 个种子，预算直至全部训练池）。kernel IVR 在 6 个可比预算中胜过 maximin 3 个，未过半数；没有策略表现出一致优势。

**局限。** 与 AREP #21 同一实验室、同类仪表；名义等效转速；固定吸气温度；仅域内点；源报告使用 REFPROP，本程序使用 CoolProp。

## 2. 较早的留出检验——AREP #21，Copeland ZS21KAE-PFV，R404A

ORNL/AHRI AREP 第21号报告（Shrestha、Sharma、Abdelaziz，2013），表A1，<https://info.ornl.gov/sites/publications/files/Pub42278.pdf>。64 个工况、吸气温度 65°F；40 / 12 / 12 划分在首次评分前冻结。

| 方法 | 流量 MARE / P95 / 最大 | 电功率 MARE / P95 / 最大 |
|---|---|---|
| 四参数 | 0.624 / 1.232 / 1.478 | 1.708 / 4.385 / 4.978 |
| 仿射 | 0.606 / 1.220 / 1.500 | 0.833 / 2.179 / 2.246 |
| AHRI 风格十系数 | **0.408 / 0.692 / 0.768** | **0.158 / 0.422 / 0.657** |

四参数模型名义 90% 区间覆盖流量 11/12、功率 12/12。这 12 个最终点后来被用于学习曲线和回放等二次分析，因此**已不再是未见数据**，也未用于挑选之后的任何方法。

## 3. 纯开发交叉验证（AREP #21 训练组）

只导出原 40 个训练组，24 个保留的校准/测试标签不在文件中。9 个凸包组固定训练，其余 31 组五折各验证一次。RBF 扩展的超参数（长度尺度 0.5、岭 0.01）事先固定。

| 方法 | 流量 MARE / P95 | 电功率 MARE / P95 |
|---|---|---|
| 四参数 | 0.709 / 1.541 | 1.278 / 2.994 |
| 仿射 | 0.617 / 1.535 | 0.676 / 1.950 |
| AHRI 风格十系数 | 0.432 / 0.935 | **0.232 / 0.596** |
| 四参数 + RBF | **0.403 / 0.984** | 0.287 / 0.863 |

控制压比后，基础模型残差与吸气绝对压力仍明显相关（偏相关：流量 0.68、功率 0.75），说明四参数关联式未捕捉这部分结构。这促成了残差扩展，并在第1节用未见数据检验。训练组只有 9 个时，该扩展的流量误差反而更差，因此默认不启用。
